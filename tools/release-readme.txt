Expense Tracker {VERSION} (Windows 10/11, 64-bit)

Start: double-click ExpenseTracker.exe. No installation and no .NET needed.
The program files are in the "app" folder; keep it next to ExpenseTracker.exe.

The app starts with 18 standard categories and no expenses: Settings -> "Load demo data" fills every screen
with a year of sample data, and Settings -> "Clear all data" removes it again.

Windows SmartScreen may warn about an unsigned app: choose "More info" -> "Run anyway".

Your data (database, backups, exports, logs, settings) is kept in
%LOCALAPPDATA%\User Name\com.companyname.expensetracker.app\Data
(the app shows the exact folder under Settings -> "Where your data is").
To remove the app, delete this folder and that data folder.

Source code and documentation (English and German):
