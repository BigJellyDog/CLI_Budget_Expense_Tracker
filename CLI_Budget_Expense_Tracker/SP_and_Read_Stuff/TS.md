## 📋 ТЗ: "ExpenseTracker" - консольное приложение учёта расходов

### Легенда (что "сказал заказчик")
> "Хочу приложение, куда я буду вносить свои расходы - сколько потратил, на что и когда. Хочу видеть, сколько я потратил за месяц, по каким категориям трачу больше всего, и чтобы данные не терялись при перезапуске программы. Плюс хочу видеть предупреждение, если я превышаю лимит по категории."

### Функциональные требования (что программа должна делать)

1. **Добавление расхода**
    - Пользователь вводит: сумму, категорию (еда, транспорт, развлечения и т.д.), дату (по умолчанию - сегодня), необязательное описание
    - Программа проверяет корректность ввода (сумма - число больше 0, дата - валидная)

2. **Просмотр расходов**
    - Показать все расходы списком
    - Отфильтровать по категории
    - Отфильтровать по периоду (за месяц, за неделю, за произвольный диапазон дат)

3. **Статистика**
    - Общая сумма трат за выбранный период
    - Сумма трат по каждой категории
    - Категория с наибольшими тратами

4. **Лимиты бюджета**
    - Пользователь задаёт лимит на категорию (например, "Еда - 300€ в месяц")
    - При добавлении расхода, если лимит превышен - вывести предупреждение

5. **Хранение данных**
    - Все расходы сохраняются в файл (JSON) и подгружаются при следующем запуске

6. **Экспорт**
    - Выгрузить отчёт за период в CSV файл

### Нефункциональные требования (как это должно быть сделано)
- Код разделён на слои: модели, логика, хранение данных, интерфейс (консоль)
- Обработка некорректного ввода без падения программы
- Юнит-тесты на ключевую логику (подсчёт сумм, проверка лимитов)
