# ТЗ v3: ExpenseTracker (MAUI)

> Консольная версия и тесты убраны (доступны в истории Git до коммита очистки).
> UI/дизайн не трогаем до конца: в конце будет новый дизайн. Сейчас важен рабочий скелет и полнота функций.
> Принцип: сначала основа и рабочие фичи, потом всё остальное. Закрывай `[ ]` → `[x]`, после этапа коммит.
> Стек: C# / .NET 10, .NET MAUI (MVVM, CommunityToolkit.Mvvm), EF Core, SQLite, DI.

## 1. Архитектура

- `CLI_Budget_Expense_Tracker.Core`: модели, сервисы, интерфейсы (без знания про EF Core)
- `CLI_Budget_Expense_Tracker.Infrastructure`: EF Core, SQLite, миграции, репозитории, импорт Revolut CSV, CSV-экспорт
- `ExpenseTracker.App`: MAUI-приложение (Views / ViewModels / Models / Services)
- Деньги только `decimal`; БД лежит рядом с `.sln` (запасной путь: `FileSystem.AppDataDirectory`)
